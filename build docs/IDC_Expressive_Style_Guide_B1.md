# Expressive Style Guide — B1
**EXPRESSIVE TIER · 2026 EDITION**
inspiredesignscollective.com

Expressive is IDC's highest-design tier. It serves churches that want a site that announces their identity before a single word is read. Every layout decision is intentional. Every section earns its space. This guide defines the rules that keep Expressive builds from becoming generic — and the license they have to be genuinely different.

---

## NEVER — NO EXCEPTIONS

### STRUCTURE
- Stack full-width sections with identical top/bottom padding all the way down the page
- Alternate white/gray/white/gray backgrounds as the only method of separating sections
- Center every headline, paragraph, and button — centering must have a reason
- Place every section in the same max-width container
- Use two consecutive sections with the same layout pattern

### HERO & CTAS
- Combine a dark overlay + centered text + more than one button in the hero — this defines a template site
- Use stock photography of any kind
- Place two competing CTAs in the hero

### COMPONENTS
- Use rounded cards with drop shadows as the default container for all content
- Repeat icon + heading + short paragraph in a row more than once per page
- Use a carousel or slider in the hero
- Include a generic Welcome paragraph nobody reads
- Use a three-column footer of link lists or testimonial sliders

### MOTION
- Animate every element on scroll
- Use bouncy, springy, or attention-seeking animation
- Apply parallax to more than one section

### TYPOGRAPHY
- Use only three type sizes (heading/sub/body) across the entire site
- Make every headline the same size and weight

---

## DEFAULT — DEVIATE ONLY WITH A REASON

### LAYOUT
- Vary section width: full-bleed, narrow reading column, and wide grid all on one page
- Left-align most body text; center only when there is a clear compositional reason
- Let at least one element per page cross a section boundary
- Use rules, lines, and whitespace to separate content instead of boxes and cards
- Three-column card grids: max one per page — flag it in your build notes with a reason

### TYPOGRAPHY & UI
- Allow headlines to break across lines intentionally — do not just let them wrap
- Vary image sizes and aspect ratios within a single page
- Use square-cornered or minimally rounded, text-forward buttons
- Use text links with an arrow or underline for all secondary actions
- Pill-shaped buttons: one style per site, max two appearances per page

### NAVIGATION
- Sticky horizontal nav is the default — functional and expected
- A single CTA button in the nav — Plan a Visit or I'm New
- Full-screen overlay, sidebar, or creative nav treatment: flag it in build notes

---

## REQUIRED — MUST BE PRESENT IN EVERY BUILD
- At least one asymmetric layout split (~1/3-2/3 or 5/12-7/12) per page
- At least one typographic scale break per page — a headline that is clearly dominant on screen
- At least one full-bleed image touching the viewport edge
- One consistent photo treatment sitewide (grade, duotone, grain, or clean — pick one and apply it)
- Small-caps or tracked uppercase labels as a secondary typographic voice (section labels, dates)
- A single sticky CTA — Plan a Visit, I'm New, or Give — never all three simultaneously

---

## EXPRESSIVE PERMISSIONS — LICENSED DEPARTURES
- Dark, charcoal, or deep-colored page backgrounds — approved for Expressive with strong typography
- Editorial typography pushed to maximum — display type as a visual element
- Parallax and staggered reveals both acceptable if used with restraint
- Photo treatment can include duotone or high-contrast grade
- Navigation may be a full design element (oversized, sidebar, or overlay)
- All Protected Clarity rules still apply without exception

---

## PROTECTED CLARITY — NEVER COMPROMISE THESE
- Service times are never buried — they belong at or immediately below the hero on every device
- Address and directions link must appear in both the header/hero area and the footer
- Primary CTA must be visible without scrolling on every device
- Contact information is never hidden behind icons alone — label everything
- Staff names and roles are always text, never image-only
- Give path reachable within two clicks from any page

---

## QUICK REFERENCE — PATTERN CHECK
- No two consecutive sections share the same layout
- Hero does not use overlay + centered text + two buttons
- At least one asymmetric split present
- Sticky CTA implemented — single action only
- Service times and address findable within one scroll
- Photo treatment consistent sitewide

---

## SYMMETRY SCALE — Expressive Target: 7 to 10
- 7 = Most restrained an Expressive build can be
- 8-9 = Default target range — strong asymmetry, clear point of view
- 10 = Maximum expression — only when photography and content support it

---

## INNER PAGES — APPROVED LAYOUTS BY TYPE

### SERMONS / MEDIA
- Editorial magazine-index layout: large featured sermon at top, smaller entries below in a staggered grid
- Never use uniform thumbnail cards in a grid — this is the default and must be avoided
- Series artwork displayed large; episode titles typographically dominant
- Filter/sort controls styled minimally — function first, never a visual centerpiece

### EVENTS
- Timeline or editorial list layout with oversized date numerals as a design element
- Never use event cards in a uniform card grid
- Featured upcoming event gets a full-width or split-layout hero treatment at top of page

### STAFF
- Never use a headshot grid as the default layout
- Approved options: asymmetric editorial per-person treatment; large single-column list with name/role/bio; or split full-height photo with bio panel
- Each staff member should feel like a considered design moment, not a database entry

### FORMS (CONTACT / GIVE / CONNECT)
- Function takes priority — creativity goes in the surrounding context and written text, not the form fields themselves
- Never use decorative borders or unusual input styling on form fields
- Surround forms with strong editorial written content, a relevant image, or a meaningful quote to provide context

---

## COLOR APPLICATION RULE
- Maximum one brand-color background section per page — brand color is an accent, not a wallpaper
- Gradients used as accents only: rules, labels, borders, or a single hero treatment per build
- Never apply a full-page gradient wash or color flood to an inner/info page
- Charcoal and white are the default surface colors — brand colors interrupt intentionally, not by default
- Every brand-color usage must have a reason; document it in your build notes

---

## CONTENT-TO-STYLE RATIO — INNER PAGES
- Target a 60/40 or 50/50 style-to-content balance on inner pages — not the 80/20 content-heavy default
- If a page is primarily text-driven, the typographic and spatial treatment must carry the visual weight
- Basic, content-heavy layouts are appropriate for Traditional tier — Expressive inner pages should not look the same
- Never let an inner page feel like it was built by a different designer than the homepage

---

## IMPORTANT NOTE FOR THIS BUILD
This style guide is the primary framework for the Inspire Designs Collective company website build. B1 rules are the starting point and default. Deviations from B1 are permitted on this build when there is a strong creative reason, but must be flagged and approved by the designer. All other documents (A1, A2, A3, A4) remain locked with no exceptions.
