# Anti-AI & Authenticity Protocol — A1
**UNIVERSAL · ALL STYLE TIERS · 2026 EDITION**
inspiredesignscollective.com

This protocol governs every Inspire Designs Collective website build. It exists because AI-generated websites share predictable patterns that make them feel generic, impersonal, and disposable. These rules break those patterns. A build that follows this protocol will not look like a template site. No two IDC builds should be interchangeable.

---

## PATTERN BLACKLIST — NEVER USE THESE

### LAYOUT PATTERNS
- Dark overlay + centered text + two pill buttons in the hero — this combination defines a template site
- Icon + heading + short paragraph repeated in a row (icon grid) — the default AI feature section
- Alternating white/gray/white/gray sections as the only method of separating content
- Rounded cards with drop shadows as the default container for all content
- Three-column footer of link lists — used on every generic church site
- Generic welcome paragraph that nobody reads

### COPY PATTERNS
- Em dashes used for emphasis or pause — a reliable marker of AI-generated text
- Marketing filler words: empower, seamless, unlock, transform, elevate, journey
- Third-person voice about the church — copy always speaks directly to the visitor in second person
- Generic opener phrases: We believe in..., Our mission is..., At [Church], we...
- Passive construction that distances the church from its own actions

### PHOTOGRAPHY PATTERNS
- Stock photography of any kind — all images must be church-provided
- Inconsistent photo treatment across pages — one grade, one style, applied everywhere
- Dark moody photography on a light-themed Traditional or Median build

---

## REQUIRED — AUTHENTICITY STANDARDS
- Every page must have a point of view — someone clearly made considered decisions, not just accepted defaults
- Copy speaks to the visitor in second person — you, your, never we hope you will
- No two builds are interchangeable — a site must feel like it could only belong to this church
- Photography is treated consistently sitewide — one grade, one approach, applied to every image
- Service times and address are findable within one scroll on every device — non-negotiable
- Every CTA is a single clear action — competing CTAs in the same section are never acceptable

---

## SELF-AUDIT — BEFORE DELIVERING ANY BUILD
- Read the homepage headline aloud. Could it belong to any other church? If yes, rewrite it.
- Count the CTAs visible above the fold on mobile. There should be exactly one.
- Look at the hero. Does it use dark overlay + centered text + two buttons? Rebuild it.
- Read the first paragraph of body copy. Does it start with We? Rewrite it to start with You.
- Check the footer. Is it three columns of link lists? Redesign it.
- Check every heading size on the page. Are they all the same size? That is a typography failure.
- Look at icon sections. Is there a row of icon + heading + paragraph? Remove or redesign it.

---

## PROTECTED COPY RULE
Client's exact words and spelling are locked. If a client provides copy — their tagline, mission statement, ministry names, or any specific phrase — use it exactly as written. Capitalization may adapt to design style. Spelling and wording never change. This is their voice, not a draft.

---

## IMPORTANT NOTE FOR THIS BUILD
This is the Inspire Designs Collective company website, not a church client site. The second person rule and ban on "we" openers apply to church client sites where the church speaks to its congregation. On this build, "we" refers to Inspire Designs speaking directly to pastors and church leaders as potential clients. First person "we" is appropriate and intentional on this site. All other A1 rules apply without exception.

Outward facing copy must always say Inspire Designs or Inspire Designs Collective. Never use the abbreviation IDC in any visitor-facing text.
